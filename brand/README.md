# Abdul Ahad — Brand kit

Generated by `npm run brand` (source: `scripts/build-brand.mjs`). Edit the script, not these files.
All lettering is converted to outlines, so the SVGs render the same everywhere, with no fonts needed.

## The mark

An open "A" — two strokes meeting at a peak — with the crossbar replaced by a single ember
particle. It references the particle system used across the website and intro film.

## Files

| File | Use it for |
| --- | --- |
| `svg/logo-mark.svg` | Mark on dark backgrounds |
| `svg/logo-mark-on-light.svg` | Mark on light backgrounds |
| `svg/logo-mark-mono-white.svg` / `-mono-black.svg` | Single-colour printing, embossing, overlays on photos |
| `svg/logo-wordmark.svg` | Mark + name on dark backgrounds (primary logo) |
| `svg/logo-wordmark-on-light.svg` | Mark + name on light backgrounds (documents, invoices, résumé) |
| `svg/logo-wordmark-mono-*.svg` | Single-colour versions of the full logo |
| `svg/app-icon.svg` / `app-icon-light.svg` | Rounded-square icon (apps, favicons, launchers) |
| `png/avatar-800.png` | Profile picture — GitHub, LinkedIn, Upwork, Slack (safe for circle crops) |
| `png/banner-1584x396.png` | LinkedIn / X header — content is right-aligned so the profile photo never covers it |
| `png/*` | PNG exports of all of the above at 1×–4× sizes, transparent where applicable |

Use the SVG wherever the tool accepts it. Use the largest PNG otherwise and let the tool scale down.

## Typography

- **Geist** (sans) — headings and body. Logo lettering is Geist SemiBold, tracking −3%.
- **Instrument Serif Italic** — accent words.
- **Geist Mono** — labels and metadata.

All three are free under the SIL Open Font License.

## Rules

- **Clear space:** keep at least the height of the ember dot × 3 empty around the logo.
- **Minimum size:** mark 16 px tall; full wordmark 96 px wide. Below that, use the mark alone.
- The ember dot is always ember, except in the mono versions.
- Don't recolour, stretch, rotate, outline or add effects to the logo.
